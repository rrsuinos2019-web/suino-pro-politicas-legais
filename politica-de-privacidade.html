Política de Privacidade

1. Quem somos

Esta Política de Privacidade explica como o Suíno Pro, desenvolvido por AgroPro Tech — Rafael Leal de Araújo, trata informações relacionadas ao uso do aplicativo.

2. Dados inseridos pelo usuário

O aplicativo pode armazenar dados de animais, lotes, reprodução, alimentação, vacinas, medicamentos, pesagens, agenda, despesas, receitas, vendas, configurações de idioma e moeda, além de fotos escolhidas pelo usuário. Esses dados são inseridos voluntariamente para permitir o funcionamento das ferramentas de gestão.

3. Dados técnicos

Podem ser tratados dados técnicos necessários ao funcionamento, como versão do aplicativo, sistema operacional, informações de erro e dados necessários para processar compras pelo Google Play. O aplicativo não solicita dados bancários diretamente; os pagamentos são processados pelo Google Play.

4. Como usamos os dados

Usamos as informações para salvar e apresentar os registros da granja, gerar cálculos e relatórios, enviar notificações solicitadas pelo usuário, manter recursos de backup e restaurar dados quando solicitado, processar compras e corrigir problemas técnicos.

5. Armazenamento local e fotos

O Suíno Pro é offline-first. Os dados são armazenados localmente no dispositivo, e as fotos dos animais podem ser mantidas no armazenamento privado do aplicativo. O usuário deve realizar backups periódicos e não deve apagar os dados do aplicativo ou desinstalá-lo sem verificar seus backups.

6. Compartilhamento

Não vendemos os dados cadastrados na granja. O compartilhamento pode ocorrer quando necessário para processar uma compra pelo Google Play, cumprir obrigação legal, atender solicitação válida do usuário ou operar serviços expressamente acionados pelo usuário.

7. Notificações e permissões

O aplicativo pode solicitar permissão para notificações, câmera e galeria de imagens. Essas permissões são usadas para as funções correspondentes, como alertas de agenda e parto e cadastro de fotos. O usuário pode alterar as permissões nas configurações do dispositivo.

8. Retenção e exclusão

Os dados permanecem no dispositivo enquanto o usuário mantiver o aplicativo e seus dados. O usuário pode excluir registros pelas funções disponíveis no aplicativo ou apagar os dados do aplicativo nas configurações do sistema. Arquivos de backup devem ser excluídos separadamente quando não forem mais necessários.

9. Segurança

Adotamos medidas técnicas razoáveis para proteger os dados no contexto de um aplicativo local. Nenhum armazenamento eletrônico é absolutamente livre de riscos; recomendamos manter o aparelho protegido e conservar cópias de backup em local seguro.

10. Crianças

O Suíno Pro é destinado a atividades de gestão e não é direcionado a crianças. Não buscamos coletar intencionalmente dados de menores de idade.

11. Alterações e contato

Esta política pode ser atualizada para refletir mudanças no aplicativo ou na legislação. A versão vigente será publicada nesta página. Para dúvidas ou solicitações relacionadas à privacidade, entre em contato com AgroPro Tech — Rafael Leal de Araújo pelo e-mail suinoproapp@gmail.com.
